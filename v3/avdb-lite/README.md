# AVDB Lite

X1080X 板块采集 + 文章浏览 + 一键 115 磁力离线。

## 功能

- 按 X1080X 板块抓取列表（JSON API）
- 抓取原帖详情，提取磁力、ED2K、预览图、大小、压缩包密码/文件名
- 插件页面展示：搜索、板块筛选、详情、封面
- 点击“发送 115”调用宿主 `/api/115/offline/add`，提交磁力/ED2K
- 115 保存目录 cid、主/备账号可配置
- 结果保存在插件加密 KV；封面缓存到插件自有目录

## 安装

1. DIAN115 → 插件 → 安装本地插件，选择 `dist/avdb.lite-0.1.0.dian115p`
2. 打开侧栏「AVDB Lite」
3. 点「设置」：
   - 填写 x1080x.com 的 Cookie（登录后从浏览器复制）
   - 如站点要求，填写 `X-CSRFToken`（也可从 Cookie 里的 `csrf_token` 自动读取）
   - 勾选要抓取的板块
   - 可选：115 保存目录 cid、主/备账号
4. 保存设置 → 点「立即抓取」
5. 抓取完成后，卡片上点「发送 115」，或在详情里逐条发送磁力/ED2K

## 说明

- 本插件不内置浏览器。X1080X 登录/Cloudflare 校验需要你提供已登录 Cookie；Cookie 失效时任务会提示“返回了登录页”。
- 未实测真实账号下的详情 JSON 字段；如果详情页没有提取到磁力，请查看任务日志里的“详情失败/结构异常”。
- 当前只实现 X1080X；色花堂/规则/自动下载是后续阶段。
- 115 提交结果只表示 115 已接受（`accepted`）；实际下载进度请在 115/宿主离线任务里查看。
