# v3 插件的离线单测

每个插件的测试与夹具放在这里（`v3/tests/<plugin>/`），**不在插件源码目录里**：

- 插件目录（`v3/<plugin>/`）只装运行时需要的东西：`plugin.json`、`jobs/`、`lib/`、`ui/`。
  官方 `starter` 模板的插件目录同样不含测试。
- 测试不进 `.dian115p` 包：宿主审查会扫描整个插件目录，测试夹具里的大段编码向量、
  夹具用例会命中「编码数据 / 远程代码」等启发式；把测试移出插件目录既让包更小，
  也让审查看到的是真实运行时代码。

跑测试：

```sh
bash scripts/v3-test.sh              # 三个插件
bash scripts/v3-test.sh music-rs     # 只跑一个
```

测试用相对路径引用插件源码：`../../<plugin>/lib/...`、`../../<plugin>/jobs/...`。
